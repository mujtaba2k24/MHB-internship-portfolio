
# Applied Linguistics Internship Portfolio

A premium academic portfolio for **Mujtaba Hussain Bhatti**, an English Applied Linguistics undergraduate at the University of Sindh, Jamshoro.

This portfolio documents the internship experience, teaching practice, institutional communication, learning activities, and reflections.

> A personal portfolio with a fictional streaming-platform look. It is not affiliated with Netflix or any other streaming service.

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production website is generated in the `dist/` folder.

## Project structure

- `src/data/portfolio.ts` — portfolio content
- `src/components/` — website sections and components
- `public/assets/` — images and visual assets
- `public/documents/` — public documents
- `vite.config.ts` — Vite configuration

## Technology

React 18, TypeScript, Vite 6, Tailwind CSS 4, Framer Motion, and Lenis.

## Deployment

The website is configured for GitHub Pages at:

`https://mujtaba2k24.github.io/MHB-internship-portfolio/`

## Updating content

Update verified portfolio information in `src/data/portfolio.ts` and the relevant components in `src/components/`.

Only publish documents and images that are appropriate for public access.
